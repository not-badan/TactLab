# Сборка переносимой версии Windows x64

Такт использует WinForms и WebView2 для собственного окна. Локальный процесс CAD запускается из вложенного CPython на 127.0.0.1. При закрытии окна или завершении процесса-родителя закрывается его канал связи, и сервер останавливается. Если заранее занять порт 18461, приложение выбирает свободный порт. Для устройств без доступного WebView2 предусмотрен запуск интерфейса в системном браузере.

## Получить ZIP из исходников

На Windows 10/11 x64 с Python 3.12 x64 и .NET Framework 4.7.2 или новее распакуйте исходники тега нужной версии и выполните в его корневой папке:

~~~powershell
py -3.12 -m venv .venv-release
.\.venv-release\Scripts\python.exe -m pip install -r windows/requirements-win64.lock
.\.venv-release\Scripts\python.exe windows/build.py --cache ..\tact-build-cache --output ..\tact-release
~~~

Сборка загружает официальный встраиваемый CPython и SDK Microsoft WebView2, сверяет их SHA-256 с зафиксированными в build.py, собирает TactLab.exe штатным компилятором Windows и формирует архив с зависимостями и их лицензиями. В каталоге результата появятся TactLab-win-x64.zip и SHA256SUMS.txt. Для пользователя все необходимые файлы приложения уже внутри ZIP. Встроенные веб-ресурсы не зависят от CDN.

## Проверить скачанный архив

~~~powershell
Get-FileHash .\TactLab-win-x64.zip -Algorithm SHA256
~~~

Сравните полученное значение с SHA256SUMS.txt из того же релиза. Контрольная сумма относится ко всему архиву. Приложение версии 1.0.0 распространяется без цифровой подписи издателя. Исходники конкретной версии доступны по тегу релиза.

## Первая проверка сборки

Распакуйте ZIP в отдельную папку с пробелом в имени. Запустите TactLab.exe, постройте панельную кнопку и рычажный концевик, сохраните комплекты через системный диалог, проверьте параметры и наличие STL и STEP в архивах. Закройте окно и убедитесь, что локальный порт освободился.
