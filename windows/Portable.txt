Такт · конструктор кнопок для Windows x64

Распакуйте весь ZIP в обычную папку и откройте TactLab.exe. Храните exe вместе с папками app и runtime. Установка Python, сеть для расчётов и права администратора не требуются.

Первая кнопка: оставьте «Панельная», задайте диаметр отверстия и толщину панели, затем нажмите «Скачать комплект». Выберите папку для ZIP. В нём STL деталей, STEP-сборка, монтажный шаблон и инструкция. Первую посадку проверьте на своём принтере.

На Windows 10/11 c Microsoft Edge WebView2 программа открывается в собственном окне. Если WebView2 недоступен, программа откроет локальный адрес в обычном браузере. Закройте окно приложения, чтобы завершить работу. Параметры интерфейса хранятся в профиле пользователя.
