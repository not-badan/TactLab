# Такт · TactLab

Параметрический генератор панельных кнопок и рычажных концевиков под тактовые переключатели Omron B3F-1000 и B3F-1002. Скачайте исходный код, запустите программу у себя и подберите размеры под свой проект. Генератор строит 3D-модель и выдаёт STL деталей, STEP-сборку, монтажный шаблон 1:1 и инструкцию.

## [Скачать для Windows x64 · ZIP, 173 МБ](https://github.com/not-badan/TactLab/releases/latest/download/TactLab-win-x64.zip)

1. Распакуйте ZIP целиком.
2. Откройте **TactLab.exe**. На Windows 10/11 с WebView2 конструктор откроется в отдельном окне. При отсутствии WebView2 используется обычный браузер.
3. Задайте размеры и нажмите **«Скачать комплект»**. Выберите, куда сохранить STL, STEP и монтажный шаблон в одном архиве.

Переносимая версия включает Python и CAD-библиотеки. Расчёты выполняются на вашем ПК. Для работы достаточно распакованной папки. [Страница релиза и контрольная сумма](https://github.com/not-badan/TactLab/releases/latest) · [Как собран EXE](windows/README.md)

## Запуск из исходников

### Windows

1. Скачайте [исходники ZIP](https://github.com/not-badan/TactLab/archive/refs/heads/main.zip) и распакуйте архив в обычную папку.
2. Если на компьютере ещё нет **Python 3.12 для Windows x64**, установите его с [python.org](https://www.python.org/downloads/release/python-31210/). В установщике оставьте включённым Python Launcher.
3. Дважды щёлкните **Start-TactLab.cmd**. При первом запуске он скачает библиотеки для расчёта моделей. Затем в браузере откроется конструктор. В следующий раз достаточно того же двойного щелчка.

Держите окно программы открытым, пока работаете. Для остановки нажмите в нём Ctrl+C. Генератор слушает только ваш компьютер. Обычно он открывается на порту 8096. Если порт занят, программа выберет свободный и покажет адрес в окне.

**С установленным Docker**

~~~
docker build -t tactlab .
docker run --rm -p 127.0.0.1:8096:8080 tactlab
~~~

Откройте http://127.0.0.1:8096/. Если порт занят, замените 8096 свободным номером в команде запуска контейнера и в адресе браузера.

## Первая деталь

Выберите исполнение, задайте диаметр отверстия и толщину панели или длину рычага. Проверьте модель в разрезе и нажмите «Скачать комплект». Для первой примерки в папке public/examples лежат кнопка Ø22 мм и концевик с рычагом 24 мм. В стартовом профиле зазор 0,30 мм задан на сторону. Подберите его для своей печати и проверьте щелчок и отпускание собранного узла.

## Добавить свой механизм

В model.py находятся геометрия деталей, исходные размеры и допустимые диапазоны. Для нового типоразмера проверьте посадку, положение ножек, ось штока и рабочий ход по чертежу компонента. Поля настроек расположены в public/index.html и main.js. В viewer.js задаются положения деталей при просмотре, в outputs.py формируются экспорт и инструкция.

После изменения клиентского кода выполните npm ci и npm run build. Для геометрических проверок установите trimesh в то же Python-окружение и запустите verify.py. Если делитесь доработкой, приложите параметры и укажите, что проверяли на модели, а что удалось напечатать и собрать. Предложения изменений приветствуются через pull request.
